# StockLog v3.75.7

## UI/UX polish
- Reworked the auto-trading positions area into a compact full-width list.
- Moved Safety Limits below positions as compact inline KPI tiles to remove the oversized empty right panel.
- Added clearer tonal hierarchy to auto-trading configuration cards and tabs.
- Removed volatile live-connection wording from the manual paper-trading holdings header; only the latest live update time is shown.
- Applied a restrained modern surface palette across Smart Analysis, Flow Analysis, Themes, and paper-trading screens.
- Improved flow cards, ranking score chips, smart-analysis surfaces, table striping, borders, shadows, and hover states for easier scanning.

## Compatibility
- No backend behavior or trading rules changed in this release.
- Gbot auto-trading, fill notifications, routing/history, theme Gbot analysis, and admin sync behavior are preserved.
