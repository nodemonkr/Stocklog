# StockLog v3.80.5

## Viewport-fit layout
- Portfolio holdings no longer use a 1460px minimum-width table. All 12 columns are proportionally fitted to the available desktop content width.
- Gbot automatic-investing holdings no longer use a 1450px minimum-width table. All 9 columns fit the content width.
- On compact screens, portfolio and automatic-investing holdings wrap inside each stock card instead of requiring horizontal scrolling.
- Removed horizontal data scrolling from smart analysis, stock-detail finance/flow tables, portfolio category data, order history, admin membership policy, chart controls, pagination, flow day grids, and Gbot decision pipeline.
- Quarterly finance cards and AI evidence cards use responsive wrapping grids rather than horizontal carousels.
- Added application-wide horizontal overflow containment as a final safety guard.

## Version
- Project/frontend/mobile version: 3.80.5
